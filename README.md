# LIGHTHOUSE :

**Check. Understand. Stay Safe.**

LIGHTHOUSE is an educational cybersecurity-awareness web prototype that helps people recognise possible warning signs in suspicious messages and URLs and learn safer online habits.

## Live Demo

https://sahanakshekhar22-ship-it.github.io/Lighthouse-/

## Features

- **Message Checker** — Checks submitted text for patterns that may indicate urgency, requests for sensitive information, unexpected rewards, payment pressure, impersonation, or other common scam warning signs.
- **Link Checker** — Examines URL text for selected warning patterns, such as unusual hostname characteristics, URL shorteners, or suspicious terms. It does not open the destination.
- **Ask LIGHTHOUSE** — Provides predefined guidance for common online-safety questions.
- **Safety Guide** — Shares practical online-safety tips.

## How It Works

The current prototype uses client-side, rule-based checks and predefined responses built with HTML, CSS, and JavaScript. It is intended for awareness and learning, not as a definitive security scanner.

## Run Locally

1. Clone or download this repository.
2. Open the project folder.
3. Open the main HTML file in a modern web browser.

No build step or package installation is required for the current standalone prototype.

## Limitations

- Results are based on simple rules and may produce false positives or miss suspicious content.
- A result cannot guarantee that a message or URL is safe or malicious.
- The Link Checker inspects URL text only; it does not visit the destination.
- Ask LIGHTHOUSE uses predefined responses, not a live AI model.
- The current version does not integrate AWS services, external APIs, live threat-intelligence feeds, a backend, or real-time website/file scanning.

## Safety and Privacy

Use LIGHTHOUSE as an educational aid, not as a substitute for independent verification or professional security tools.

Do not share passwords, one-time passcodes, financial details, or other sensitive personal information. If a message seems suspicious, avoid clicking its links and verify the request through an official channel you find independently.
